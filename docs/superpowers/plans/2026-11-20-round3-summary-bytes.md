# Round 3 summary scoring under a read budget

**Goal** Compare GQA Quest and single centroid scoring under equal modeled external reads using A1 and affine32.

**Architecture** Use the packed page layout to decide the page quota before scoring. Keep the existing Dense Prefill and grouped FP32 Mask Decode; insert a scorer that accepts only Query and encoded page summaries. Validate Gather against Mask on sampled states. Use the existing Qwen and pinned RULER generators, with fresh calibration and test splits.

- Freeze the modeled layout at 16-byte alignment. Four bytes per optional or protected page for a packed selected page index. All summary records are read, including protected pages. Fixed 32 Sink and 128 Local tokens map to physical pages and are charged once. The final page is protected, so each remaining page has identical cost. The common ceiling is an integer percentage of packed Dense K/V reads, including alignment.
- Encode one FP16 scale and one byte of valid length for the INT8 centroid. Encode two FP16 scales for the Quest INT8 min/max pair with one valid-length byte. Apply outward rounding for Quest extrema and audit containment. Calibrate Quest softmax-sum and max-shift-max independently. Log row-alignment bytes, reads and writes, selection passes and score SRAM separately.
- Prepare official VT and NIAH Multi-Value at 16K with 16 calibration prompts each and separate seeds. Prepare VT at 32K with 16 calibration prompts. Use task-default output reservations (30 for VT, 128 for Multi-Value, 50 for FWE fallback). Use contained VT prefixes and official in-context examples. Run FWE 16K fallback if Dense BF16 VT official score falls below 90% at either length.
- Compare Dense BF16, Dense KV4, 5%/10% Oracle A1 and whole-scan 10%/15%/20% byte settings. Add paired P32/P64 at 16K and 15% bytes. Replay equal page counts on sampled Dense KV4 states for rankings, output tails and gold recall. FP32 centroid is a shadow diagnostic. Add a new candidate only if calibration provides the proposed failure evidence.
- Preserve previous runner defaults and verify old tests and fresh edge fixtures. Check one prompt before the full run, then run with atomic prompt bundles, source/data checksums and one completion notification.
- Freeze formal comparisons from calibration with task-specific Dense viability, Oracle retention and observed task discrimination. Decide sample size and confidence procedure before test. Keep workpoint summaries, byte tables and paired results in a new output directory. Report Gather timing as a separate reference measurement. Verify packed read/write prototype before any cross-model or hardware expansion.

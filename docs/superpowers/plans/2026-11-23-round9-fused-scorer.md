# Round 9 Mean6+Radius2 融合评分器

1. 写入并验证独立集质量与物理成本判定，保留 Round 8 原始结果。评分器使用同一 16-lane、Q8 乘加口径和 Q24 系数尾部，验证 Quest、串行 Mean+Radius、融合 Mean+Radius 与等吞吐串行对照。
2. 用同一份校准 Q 和摘要并排检查 FP32、整数分数、稳定 Top-k 和 RTL 位级结果。用同库综合，记录吞吐、面积、状态、时序及切换活动口径。
3. 在固定 64-bin 安全回退、原始 KV 和 5%/7% 硬预算下调节共同预留规则。先用 4 条提示匹配实际平均读量，随后在其余校准提示验证选定点。10% INT6 用固定单遍 K 作跨预算参考。
4. 冻结通过匹配的点、数据哈希和判定公式。独立分数改善路线要求读量差在 1% 内、至少 +1 pp、95% 配对下界大于零。等质量省读路线要求该下界至少 −1 pp 且每答案读量至少节省 10%。两条路线均要求逐组步零超限。
5. 将实测数值小模块吞吐和适用时钟口径接入依赖模型，报告剩余复杂度和扩展判定。验证后同步脚本、协议和结果至 GitHub main。

# 首轮 16K Minimal Probe：探索性结果

日期：2026-11-18。研究依据：V1.1 §5.1。状态：真实模型探索实验已完成；Gate 1 尚未判定。

## 主要发现

在这批探索数据上，A3 在 9 个预算/目标组合中均降低平均剩余缺口，P5 覆盖率在 7 个组合提高、2 个不变。P95 输出相对误差在 5 个组合下降、4 个上升：覆盖改善没有稳定转化为输出尾部改善。动态排序发生改变本身不能证明方法有效。

因此目前支持继续做正式数据验证，尚不足以启动复杂候选前沿或硬件结论。不能将当前结果称为 Gate 1 通过。

## 实验设置与复现

- 工作站：RTX 3090；Python 3.12.3；PyTorch 2.5.1+cu121；Transformers 4.51.3。
- 模型：Qwen3-4B-Instruct-2507，Qwen 官方 ModelScope snapshot `2de2439ea21be1dc5cb21f22f88af07e43393cbb`；所有文件已校验 SHA-256。
- 模型权重 BF16；K/V 在所有层的实际 Attention 路径量化再解量化。逐 Token/Head/32 通道对称 INT4 数值参考，FP16 scale，K 在 RoPE 后量化。缓存实际存储为解量化 BF16，未做压缩/性能实现。
- 4K 冒烟：1 个提示、3 个层、1 个 KV Group、2 步，6 条 Trace，324 组参数评估。
- 16K：2 个固定种子的自定义键值检索提示，输入精确为 16,384 tokens；层 0/7/14/21/28/35，全部 8 个 KV Groups，每个提示 4 个 Decode Steps，共 384 条 Trace。
- 每条 Trace 含 4 个 Query Heads；汇总的 1,536 个 Query-Head 观测有关联，独立提示仅 2 个，不提供显著性/置信区间结论。
- Page=32，Sink=1 Page，Local=128 Tokens，保护计入总预算。Decode 长度为 16,385–16,388，Local 跨 5 页，与 Sink 合计 6 个保护页。
- J=513；预算 B=floor(J×比例)，5%/10%/20% 对应 25/51/102 个物理页；所有方法严格补足同一预算。
- 比较 A1、A3、A3-B(b=1/4/8/16) × 3 个预算 × 3 个目标，每条 Trace 54 组，总计 20,736 组结果。
- 全部选择器共用相同 Logits 与 V。Dense 与 Sparse 离线输出用 FP64 稳定 Softmax，Sparse 在选中原始 Logits 上重算。

运行命令、精确输入 Token IDs、随机种子、样本/层/组/步信息、量化配置、代码哈希与依赖版本均保存在结果目录和 `requirements.lock.txt`。`scripts/run_workstation.py` 可运行完整流程；新结果必须使用新目录。

## 限制与下一步

这 2 个提示是自定义探索集，不能当作官方 RULER/LongBench；4 步采集输出被长度截断，未形成完整答案，因此没有计算任务准确率。当前仅完成 Qwen3 主模型、固定预算、Oracle Trace 路径；尚未跑 Qwen2.5、32K、256–1024 步长 Decode、自适应完整实验或闭环 Sparse Decode。

优先在冻结的正式 RULER 检索子任务上扩充独立提示，预先固定 Gate 1 判据，并诊断 p=0.9 的尾部退化。随后用第二个 GQA 比例模型复核。Gate 1 收益可靠后，再推进 A3-C/A4/A4-B；实际 Metadata 评分、真实压缩 KV4 与硬件成本属于后续阶段。

目前未提供排序/比较、候选列表访问、覆盖累加和缺口刷新次数的完整计费；不能据此给出部署成本结论。未运行的阶段均保持未验证状态，避免将参考计算误报为部署收益。

原始研究方案未改动。

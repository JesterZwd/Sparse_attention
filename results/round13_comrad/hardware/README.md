# CoMRAD 同边界前端

144 B 和 112 B 两路各综合 2 槽/2 信用、4/2、4/3。每路使用相同的整数尾部、每拍双发系数、四头合组输出和 512 B 有序接收 FIFO。记录槽占用从第一字节到最后一个 dot 发射，结果信用从第一个 dot 发射到该结果被下游接收。跨记录的 32 B burst 同一拍写入两个独立槽，各写 16 B。每个记录存放 176 位已生成系数和 32 位页标签。每条结果含四个 48 位分数、页标签和 count，合计 232 位。接收 FIFO 还原样保存 16 个 LAST 位。Query 更新在上一 epoch 排空后完成。

## 对拍

每个配置检查了 131 条合成记录的连续流和阻塞流，以及 6 个真实 Query epoch 的 102 条记录。阻塞流同时包含独立随机 input/output 停顿和一次超过 200 拍的长输出停顿。对拍逐条检查有序接收 FIFO 的数据和 LAST、Q24 系数、分数、页标签和多 epoch 切换，并记录最高在途量。原 Round 12 函数模型以内部记录完成边为参考，逐条核对完整记录、首 dot、释放边和结果写回的边序。

| 记录 | 槽/信用 | 持续拍/组记录 | 连续流槽满拍 | 系数等待拍 | 信用等待拍 |
|---|---:|---:|---:|---:|---:|
| 144 B | 2/2 | 15.0 | 1,340 | 855 | 0 |
| 144 B | 4/2 | 8.5 | 500 | 26 | 64 |
| 144 B | 4/3 | 8.0 | 440 | 26 | 0 |
| 112 B | 2/2 | 13.0 | 1,213 | 856 | 0 |
| 112 B | 4/2 | 7.5 | 501 | 26 | 192 |

表中的槽阻塞观测点在输入端，允许与 dot 有效执行重叠。后两列是 dot 端互斥等待。112 B 的 4/3 在扣除两个 epoch 的启动等待后，对应持续的 6、6、6、8 拍输出节奏。

## 同约束综合

| 记录 | 槽/信用 | 临界周期 ns | ns/组记录 | 首输出 ns | 面积 µm² |
|---|---:|---:|---:|---:|---:|
| 144 B | 2/2 | 1.66351 | 24.953 | 59.886 | 245,308.13 |
| 144 B | 4/2 | 1.65794 | 14.093 | 59.686 | 274,328.73 |
| 144 B | 4/3 | 1.75119 | 14.009 | 63.043 | 274,709.90 |
| 112 B | 2/2 | 1.66961 | 21.705 | 55.097 | 228,998.87 |
| 112 B | 4/2 | 1.76599 | 13.245 | 58.278 | 246,632.54 |
| 112 B | 4/3 | 1.74542 | 11.345 | 57.599 | 248,653.08 |

4/3 在两种记录中均得到最小的持续 ns/记录。与匹配的 144 B 4/3 比较，112 B 的组服务时间降低 19.02%，映射面积降低 9.49%。112 B 从 2/2 到 4/3 的持续服务时间降低 47.73%，映射面积增加 8.58%。四槽 112 B 的记录数据容量为 448 B，四槽 144 B 为 576 B。两路另有各自的系数、标签、共用规格的 512 B 接收容量和 87 B 结果容量。各配置均未达到 1.25 ns。

112 B 4/3 的慢路径在尾部部分积，144 B 4/3 在尾部宽加法。增加槽位和信用后，112 B 持续输出距离 6 拍点积下界为每条 0.5 拍，深容量未造成映射后服务倒退。Dot-First 保留为后续定向消融。模型分别使用各自映射周期和 786 条逐边重现的记录，并保留同步 FIFO 一拍及额外 CDC 假设。

## 复现

```sh
export OPENBLAS_NUM_THREADS=1 OMP_NUM_THREADS=1
round13_hw=.cache/round13/hardware_recheck
.venv/bin/python scripts/check_round13_rtl.py \
  --fixtures results/round13_comrad/hardware/fixtures --output "$round13_hw"
.venv/bin/python scripts/synth_round13.py \
  --lib /path/to/NangateOpenCellLibrary_typical.lib --output "$round13_hw"
.venv/bin/python -m scripts.calibrate_round13_frontend --hardware "$round13_hw"
```

除了合成刺激，脚本会读取 Round 12 保存的 128、96 维整数参考向量，仓库内附 12 个原始向量和对应哈希。综合工具从 PATH 或 `.cache/round9/tools/bin` 读取。标准单元映射包含接收 FIFO 的寄存器和控制，时序值来自同一 Nangate45 typical 库、1.25 ns 约束、BUF_X1 输入驱动、5 fF 输出负载下的布线前 STA。Liberty 的 SHA256 为 `8d540a4d4cf6d09d27c87ad067857a9c0c2eeb023ab7a56e058cd3113db4e9b1`。物理 SRAM 宏和跨时钟域接口由回填模型单独表示。 [工具版本与 STA 约束](synthesis.json)
